探索系統

系統介紹

本專題使用 Python 取得台灣股票歷史資料， 並透過 Gemini AI 分析近期股價趨勢、 價格變化與可能風險，協助使用者理解股票資訊。

核心功能

股票資料查詢

取得股票近期開盤價、最高價、最低價、收盤價與成交量。

股價圖表展示

使用 Matplotlib 繪製股價與成交量圖表。

Gemini AI 分析

利用 AI 分析近期趨勢、價格變化與潛在風險。

系統操作方式

步驟一：安裝 Python 與專案所需套件。

步驟二：在專案根目錄設定 Gemini API Key。

步驟三：開啟終端機，輸入 uv run main.py。

步驟四：輸入台灣上市股票代號，例如 2330。

步驟五：系統取得歷史股價資料，並透過 Gemini AI 進行分析。

步驟六：分析結果儲存為 JSON，供網站讀取與展示。

目前網站使用範例 JSON 展示版面，並非即時 AI 分析結果。

本機與 Docker 執行方式比較

本專題提供本機與 Docker 兩種執行方式，方便使用者依照環境選擇。

比較項目 本機執行 Docker 執行
執行環境 使用者電腦安裝 Python 透過 Docker 容器執行
套件管理 使用 uv 安裝套件 由 Dockerfile 自動安裝套件
環境一致性 可能受電腦環境影響 較容易維持環境一致
API Key 設定 透過 .env 設定 透過 --env-file 傳入
啟動方式 uv run main.py docker run -it --rm --env-file .env ai-stock-analysis

AI 技術與使用說明

本專題使用 Google Gemini API，透過 Streaming 串流輸出與 Structured Output 結構化輸出產生分析結果。

使用者可在本機執行 Python 程式，輸入股票代號進行分析。
